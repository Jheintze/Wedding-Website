# Wedding Website

A responsive wedding website built for a real wedding event. The website provides guests with important information about the event, location, accommodation, schedule, and RSVP.

## Live Demo

https://jheintze.github.io/Wedding-Website/

## Features

- Responsive design for desktop and mobile devices
- Wedding information sections
- Accommodation recommendations
- Location and directions
- RSVP integration
- Mobile navigation menu
- Custom illustrations and visual design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Highlights

- Built from scratch without a frontend framework to strengthen core web development fundamentals.
- Focused on responsive design, semantic HTML, and clean CSS structure.
- Developed for a real-world wedding use case.
